# 微型課程｜課程大綱

本課程由 Python 程式設計與資料處理出發，逐步學習監督式學習、分類模型、影像處理與大型語言模型 API，最後透過 Kaggle 專題整合資料分析、模型建置、評估與改進的流程。

## 01｜Python 數據處理與程式複習

以 Python 基礎語法為起點，練習操作資料、進行數值計算與製作統計圖表。

- **第一節｜Python 程式基礎**：變數與資料型態、串列（list）、字典（dict）、條件判斷、迴圈及函式。
- **第二節｜NumPy 陣列運算**：陣列的建立、索引與切片、向量化運算、條件篩選及基本統計。
- **第三節｜Pandas 與資料視覺化**：讀取 CSV、資料選取與清理、分組彙整，以及使用 Matplotlib 繪製統計圖表。

## 02｜監督式學習實作

以 `Taipei_house.csv` 的臺北市房價資料為案例，認識如何從資料建立數值預測模型。

- **第一節｜認識監督式學習**：特徵（X）與標籤（y）、房價資料探索、散佈圖，以及訓練集與測試集的切分。
- **第二節｜線性迴歸模型**：使用 LinearRegression 訓練模型、進行預測，並理解斜率、截距與殘差。
- **第三節｜模型評估與改善**：使用 MAE、R² 評估預測結果，比較不同特徵組合對房價預測的影響。

## 03｜分類模型與評估

以 `iris_classification.csv` 的鳶尾花資料為案例，學習分類模型的建立與評估方法。

- **第一節｜認識分類問題**：類別標籤、分類特徵、資料分布、散佈圖與訓練／測試資料切分。
- **第二節｜邏輯斯迴歸分類**：使用 LogisticRegression 訓練與預測、查看分類機率，以及解讀準確率與混淆矩陣。
- **第三節｜決策樹與模型比較**：調整決策樹深度、觀察欠擬合與過度擬合，並認識 Precision 與 Recall。

## 04｜影像處理與 OpenCV

從數位影像的像素與陣列表示開始，實作常見影像處理方法，並認識物件偵測的基本概念。

- **第一節｜數位影像基礎**：解析度、像素、影像陣列、RGB／BGR 色彩通道，以及影像的讀取、顯示與儲存。
- **第二節｜基礎影像處理**：影像縮放、裁切、灰階轉換、二值化、高斯模糊與影像處理流程。
- **第三節｜影像特徵與物件偵測**：Canny 邊緣偵測、HSV 顏色空間、顏色遮罩，以及 YOLO 物件偵測、邊界框與標註座標。

## 05｜LLM API 運用實務

認識大型語言模型的運作概念，練習透過 Python 串接 Gemini API，設計具備對話能力的應用程式。

- **第一節｜LLM、Prompt 與 API**：Token、提示詞設計、API 請求與回應、API Key 及環境變數。
- **第二節｜Python 串接 Gemini API**：建立用戶端、送出問題、取得模型回覆、設定 System Instruction 及處理呼叫錯誤。
- **第三節｜多輪對話與資訊驗證**：對話脈絡、固定欄位輸出、生成內容查證、Token 使用量，以及 Python 學習助理實作。

## 06｜課堂專題綜合實作

以 Kaggle 的 **Give Me Some Credit** 信用風險預測競賽為專題，整合資料前處理、分類模型、評估與持續改善的流程。

- **第一節｜競賽與資料探索**：認識競賽目標、讀取訓練與測試資料、辨識特徵與標籤，並處理缺失值及觀察類別分布。
- **第二節｜建立與評估模型**：運用資料前處理流程與 LogisticRegression 建立分類模型，使用 ROC-AUC 評估預測表現。
- **第三節｜提交與模型改進**：產生 `submission.csv`、體驗 Kaggle 提交及成績比較，並透過 AI 輔助修改程式、記錄實驗與比較結果。
